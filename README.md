# Business-KPI-Dashboard
## Project Overview
The Business KPI Dashboard analyzes business
performance using key performance indicators
(KPIs) such as revenue, profit, and orders.

## Objectives
- Calculate important business KPIs.
- Analyze monthly revenue and profit.
- Calculate Average Order Value.
- Measure profit margin.
- Visualize business performance using charts.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Key Performance Indicators
1. Total Revenue
2. Total Profit
3. Total Orders
4. Average Order Value (AOV)
5. Profit Margin

## Installation
Install the required libraries:

```bash
pip install pandas matplotlib
```

## How to Run
Execute the following command:

```bash
python kpi_dashboard.py
```

## Output
- Business KPI summary
- Monthly sales data
- Revenue line chart
- Profit bar chart
- Dashboard image

## Conclusion
This project helps understand business performance
through KPI calculations and visualizations.
It supports data-driven business decisions.
